Aide Ski360

Questions fréquentes et contact

Urgence en montagne : appelez le 112. Le mode secours affiche les coordonnées GPS et propose un partage par SMS. Un SOS ou une alerte de chute Ski360 prévient votre squad, pas les services de secours.

Comment créer ou rejoindre un squad ?

Onglet Squad → « Créer un squad », puis partagez le code d'invitation, le QR code ou le lien avec vos amis. Ils choisissent « Rejoindre avec un code ». Un squad compte jusqu'à 30 membres. Les fonctions réelles utilisent un compte anonyme créé automatiquement, sans inscription manuelle. Désactivez les deux options de démo pour rejoindre un vrai squad.

Si vous êtes déjà dans un squad, rejoindre un autre groupe demande une confirmation : vous quittez le précédent et perdez l'accès à sa carte, son chat et vos statistiques de saison dans ce groupe.

Comment essayer Ski360 sans être en station ?

Dans Squad → Profil & réglages → Mode démo, activez « GPS simulé (démo) » et, si souhaité, « 4 amis simulés en temps réel ». Vous pouvez ensuite démarrer une session depuis la carte.

Chaque option active une démo locale : votre adhésion réelle est conservée et la connexion à votre squad réel est suspendue. Aucune position, alerte ou statistique de démo n'est transmise au serveur ; aucun entraînement simulé n'est enregistré dans Santé. Les sessions portent la mention « Démo » dans le journal et sont exclues des records, classements et compteurs réels de matériel. Terminez la session avant de modifier les options de démo. Si une session interrompue attend une décision, reprenez-la ou supprimez-la d'abord.

Est-ce que l'enregistrement continue écran verrouillé ?

Pendant une session réelle, l'enregistrement et le partage avec votre squad continuent écran verrouillé, avec une Live Activity. L'accès à la position doit être autorisé. L'autorisation « Toujours » permet aussi à iOS de relancer le suivi après certaines interruptions ; une fermeture forcée de l'app ou des restrictions système peuvent empêcher cette reprise.

Hors session, le réglage « Visible par mon squad écran verrouillé », dans Squad → Profil & réglages → Partage avec le squad, est désactivé par défaut. Si vous l'activez, le partage reste limité à une station et au jour où vous avez skié. Vous pouvez le couper à tout moment.

Pourquoi une session ne démarre-t-elle pas ou n'est-elle pas enregistrée ?

Autorisez l'accès à la position dans Réglages iOS pour une session réelle. Un ancien enregistrement interrompu doit être repris ou supprimé avant d'en créer un autre. Le mode démo permet d'essayer l'app lorsque vous ne pouvez pas recevoir de GPS réel.

Une session terminée avec moins de deux positions GPS exploitables ne peut pas être enregistrée ; l'app vous l'indique. À l'intérieur d'un bâtiment ou avec un signal très faible, sortez dans un endroit dégagé puis réessayez. Si le journal est indisponible, l'app bloque le démarrage afin de ne pas présenter un enregistrement comme sauvegardé.

La durée comprend-elle les pauses ? Et l'export Santé ?

Les nouvelles sessions enregistrent leur durée active, pauses exclues. Les sessions créées par une ancienne version peuvent conserver leur durée totale d'origine.

Dans Squad → Profil & réglages → Apple Santé, « Enregistrer mes sessions dans Santé » active l'export des sessions réelles. Autorisez les entraînements ; la distance, les calories estimées et le tracé ne sont ajoutés que si vous autorisez ces catégories. Les pauses sont transmises à Santé. Ski360 ne lit pas votre historique Santé et n'y écrit aucune session démo.

Comment économiser la batterie et choisir les alertes ?

Ski360 réduit la précision et la fréquence des mises à jour GPS après un arrêt prolongé. Par grand froid, gardez le téléphone dans une poche intérieure. Le partage hors session est facultatif et désactivé par défaut.

Le réglage « Prévenir le squad si ma batterie est faible » est également désactivé par défaut. S'il est activé, une alerte peut partir à 15 % ou moins pendant une session réelle ou un partage hors session autorisé. Cette alerte indique le niveau de batterie et ne contient aucune coordonnée.

« Alertes du squad app fermée » permet de recevoir les notifications du squad selon vos autorisations iOS, le réseau et la disponibilité du service. Leur réception n'est pas garantie : en cas d'urgence, appelez les secours.

Comment signaler un message ou bloquer un membre ?

Dans les Messages du squad, ouvrez le menu d'un message reçu avec le bouton à trois points ou un appui prolongé. « Signaler » permet de choisir un motif et d'envoyer le contenu à la modération. Attendez la confirmation d'envoi ; si une erreur apparaît, réessayez avec du réseau. Un signalement ne bloque pas automatiquement l'auteur.

« Bloquer » masque les messages et alertes non vitales de ce membre sur votre téléphone. Pour débloquer quelqu'un, ouvrez Squad → Profil & réglages → Mes données → « Membres bloqués », également accessible depuis le chat. Les SOS et alertes de chute restent visibles pour la sécurité.

Le masquage dans l'app est immédiat. Le filtrage des notifications reçues app fermée nécessite la synchronisation des identifiants bloqués avec le serveur. Sans réseau, ou avant cette synchronisation, une notification peut encore arriver. Le filtre de langage grossier en français et en anglais limite certains contenus à l'envoi et à l'affichage ; il ne remplace pas les signalements.

Et sans réseau en altitude ?

L'enregistrement GPS fonctionne sans réseau. Préparez le plan des pistes et des remontées depuis le sélecteur de station avant la sortie. Les tuiles déjà consultées peuvent rester dans le cache local, mais les fonds cartographiques et données non téléchargées ne sont pas garantis hors connexion. Les échanges avec le squad et l'envoi d'un signalement nécessitent du réseau.

Pourquoi un ami n'apparaît-il plus sur la carte ?

Un ami devient « Hors ligne » après environ deux minutes sans nouvelle position. Il peut manquer de réseau ou de batterie, avoir coupé le partage en veille ou activé la démo locale. Une position ancienne ne doit pas être considérée comme sa position actuelle.

Comment supprimer mon compte et mon journal ?

Squad → Profil & réglages → Mes données → « Supprimer mon compte Ski360 » supprime le compte serveur, ses adhésions, ses statistiques de saison et ses données de notifications. Les sessions du journal restent sur ce téléphone et se suppriment séparément dans Journal.

Les copies de signalements peuvent être conservées pour leur traitement ; les liens techniques vers un compte ou un squad supprimé sont retirés. Consultez la politique de confidentialité pour le détail.

Contact

Pour un problème technique ou une suggestion, ouvrez une demande d'assistance avec votre modèle d'iPhone et votre version d'iOS ; un compte GitHub gratuit est nécessaire. Les demandes GitHub sont publiques : ne publiez ni position, ni code de squad, ni copie du contenu signalé. Utilisez « Signaler » dans l'app pour transmettre un contenu à la modération. Pour une demande relative à vos données, demandez d'abord un contact sans exposer d'information personnelle.

Need help? Open a support request with your iPhone model and iOS version. GitHub issues are public: never post your location, squad code or reported content. Report received messages inside the app. Demo mode stays local, and Health export only includes real sessions.
